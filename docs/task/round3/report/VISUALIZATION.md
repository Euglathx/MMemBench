## 修复方案对比

### 方案1: 调整Hard Scores默认值

**变化**: 0.1-0.3 → 0.5

```
Before (默认值=0.1-0.3):
correctness: 0.6*1.0 + 0.4*0.1 = 0.64 ✗
final score: 0.688 ✗

After (默认值=0.5):
correctness: 0.6*1.0 + 0.4*0.5 = 0.80 ✓
final score: 0.800 ✓

改进: +16.3% ✓✓
```

### 方案2: Hard Scores仅作Fallback

**变化**: 始终混合 → 仅fallback

```
Before:
final = 0.6*llm + 0.4*hard = 0.6*1.0 + 0.4*0.1 = 0.64 ✗

After:
final = llm (if available) = 1.0 ✓

改进: +56.3% ✓✓✓
```

### 方案3: 提高LLM Judge权重

**变化**: w=0.6 → w=0.8 或 1.0

```
Before (w=0.6):
final = 0.6*1.0 + 0.4*0.1 = 0.64 ✗

After (w=0.8):
final = 0.8*1.0 + 0.2*0.1 = 0.82 ✓
改进: +28.1% ✓✓

After (w=1.0):
final = 1.0*1.0 + 0.0*0.1 = 1.00 ✓
改进: +56.3% ✓✓✓
```
