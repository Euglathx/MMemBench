## 如何使用这些任务文档

### 并行工作
1. 打开多个终端/编辑器窗口
2. 每个窗口负责一个Task
3. 按照各自的task文档独立开发
4. 阶段内所有任务完成后，运行同步验证

### 每个任务文档包含
- **任务目标**: 要解决的具体问题
- **需要修改的文件**: 精确到行号
- **接口定义**: 确保不同任务之间不冲突
- **验证脚本**: 独立验证每个任务的完成度
- **协作要求**: 与其他任务的依赖关系

### 同步点
每个阶段结束时需要同步验证：
```bash
# 阶段1完成后
python task/verify_phase1.py

# 阶段2完成后
python task/verify_phase2.py

# 最终验证
python task/verify_all.py
```
